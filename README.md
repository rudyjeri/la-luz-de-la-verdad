# La Luz de la Verdad

Sitio web adventista — apologética, profecía y recursos bíblicos.

## App principal (React + Vite)

```bash
cd frontend
npm install
npm run dev
```

Build de producción:

```bash
cd frontend
npm install
npm run build
```

La salida queda en `frontend/dist`.

## Despliegue VPS

Subir el contenido de `frontend/dist` a `/var/www/luz-de-la-verdad` en el VPS.
